# Restaurant Menu

A static restaurant menu site built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. The menu loads products, categories, and basket
data from `https://restaurant.stepprojects.ge/api`.

## Deploy

The GitHub Actions workflow deploys the contents of this repository to GitHub
Pages whenever a commit is pushed to `main`. It can also be started manually
from the **Actions** tab.
